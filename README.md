# single-leg-landing-kinematic
Kinematic Analysis of single-leg Landing using MATLAB 
Single-Leg Landing Kinematic Analysis
Kinematic analysis of the lower limb during a single-leg landing task using MATLAB.
Methods
Motion capture data processing
Low-pass Butterworth filtering (4th order, 7 Hz)
Definition of anatomical coordinate systems
3D segment angle analysis
Hip, knee, and ankle kinematics
Software
MATLAB
